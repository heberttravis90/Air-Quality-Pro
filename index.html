Package transfer

Air Quality Pro works offline. On Android, Share uses the phone share sheet when supported. If direct file sharing is unavailable, the package downloads so it can be attached to email/text/Drive. The receiving device imports the same package here.

Current v1.2 transfer is device-to-device package sharing. True automatic cloud delivery requires a secured team backend/account system; this data structure is built to plug into that next.
